# Legacy skills (do not use for new runs)

These two skills describe the manual method: hand-written `dl.sh`, `ab.sh` and `campaign.sh` scripts, and a hold job
driven through `ctrl/`. The runner was built from them, so we keep them as the record of where each runner step came
from (`scripts/runner/runner.sh` cites their templates). Some facts in them are out of date.

To run a campaign, use [`skills/arbor-ci-run`](../arbor-ci-run/SKILL.md).
